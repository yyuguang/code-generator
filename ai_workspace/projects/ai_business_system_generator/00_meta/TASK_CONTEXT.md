# 原始任务描述

用户希望构建一个面向中后台业务开发场景的 AI 辅助代码生成平台。用户通过自然语言输入业务需求，系统自动完成需求解析、结构化规格提取、规则校验、模板化代码生成、工程预览与导出，最终生成可直接运行或二次开发的 Spring Boot Maven 项目代码。

## 用户明确目标

- 减少中后台重复性 CRUD 开发工作
- 提升业务模块从需求到代码的交付速度
- 将自然语言需求转化为统一技术规格
- 利用模板与规则校验提升生成稳定性
- 为后续扩展前端生成、知识库积累、多轮需求澄清打基础

# 初始理解

本任务不是简单代码片段生成工具，而是一个由统一规格中心驱动的 AI 业务系统生成平台，核心由三层能力构成：

1. 需求结构化平台：将自然语言业务需求转化为可机器消费、可人工审阅的标准规格。
2. 工程代码生成平台：基于统一规格稳定生成数据库脚本与 Spring Boot 后端工程骨架。
3. 研发提效平台：通过 AI 提案、规则兜底、模板渲染和导出能力减少重复劳动。

# 范围初判

## 当前确定范围

- 第一版聚焦单业务模块生成
- 规格输出采用 JSON/YAML 与 Markdown 双产物思路，事实源以 JSON 为主
- 主流程采用：自然语言需求输入 -> AI 结构化解析 -> 规格校验 -> 模板生成代码 -> 工程打包导出
- 用户在代码生成前必须审阅并可编辑规格

## 暂不进入范围

- 多模块关联建模自动化
- 复杂业务流程编排代码生成
- 前端页面代码生成
- 权限系统自动建模
- 多轮对话式需求澄清闭环
